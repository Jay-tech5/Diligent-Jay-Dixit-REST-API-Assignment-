# Diligent REST API Assignment

A modular REST API built with Node.js and Express.

## Project Structure

```
├── public/
├── src/
│   ├── controllers/
│   ├── data/
│   ├── models/
│   ├── routes/
│   ├── utils/
│   ├── app.js
│   └── server.js
├── tests/
├── .gitignore
├── AI_NOTES.md
├── package-lock.json
├── package.json
└── README.md
```

## Getting Started

### Installation

```bash
npm install
```

### Running the Application

- **Development Mode:** `npm run dev`
- **Production Mode:** `npm start`
- **Run Tests:** `npm test`
